## 测试环境

- 程序：Standalone 1.0.0。
- 设备：两台实体 Windows 电脑，一台笔记本位于布局左侧，一台本机位于右侧。
- 安装目录：两端均为 `C:\Program Files\Mouse Without Borders Standalone`。
- 运行模式：普通用户模式，未启用独立版 SYSTEM 服务模式。
- 旧版处理：两端原 Microsoft Garage Mouse without Borders 2.2.1.327 已卸载，旧配置已备份。本次不属于新旧版本互通测试。
- 连接配置：两端使用相同配对密钥，并配置电脑名称到局域网 IP 的固定映射。此公开记录省略实际主机名与地址，不记录配对密钥。
- 网络条件：两端网络类别均为 Public，测试时额外配置了仅允许对端 IP 的规则，详见下文。

## 当次测试的防火墙例外

安装器默认创建 Private / LocalSubnet 规则，不覆盖当次使用的 Public 网络。测试另行添加并保留了名为 `MouseWithoutBorders-Standalone-PeerTest` 的规则：

- 仅允许新版主程序的完整路径。
- 仅适用于 Public 网络、TCP 15100/15101。
- 每端的远端地址限制为对方单个局域网 IP。
- 未改变系统网络类别。

这条规则由部署测试添加，**不属于安装器默认规则，当前卸载流程不会自动删除它**。清理当次测试部署时需另行移除。设备 IP 变化后，还需同步更新该规则与程序 IP 映射。
