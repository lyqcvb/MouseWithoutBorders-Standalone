# 使用指南

本指南适用于 Mouse Without Borders (Standalone)。界面默认使用简体中文，支持英文；下文保留英文选项名，便于对照两种语言。打开设置窗口，在顶部 **语言 / Language** 中选择 **简体中文** 或 **English**，切换立即生效并自动保存，无需重启。没有语言配置的旧版用户升级后默认使用中文。

## 安装前准备

- 至少两台网络互通的 Windows x64 电脑；当前构建最低要求为 Windows 10 2004（19041）。
- 在每台电脑上使用相同版本的独立版。
- 退出其他版本的 Mouse Without Borders。PowerToys 版与本项目共享部分设置路径和服务名称，请避免同时运行。
- 在可信的局域网中使用。安装器默认防火墙规则仅覆盖专用网络的本地子网。

安装包已包含 .NET 运行时，使用电脑无需安装 SDK。安装时需要管理员权限，日常普通桌面使用可以普通用户身份运行。

## 安装与首次启动

1. 在每台电脑上运行本项目的 `Setup.exe`，完成安装向导。
2. 按需选择桌面快捷方式。登录自启默认选中，会在所有用户的启动文件夹创建入口，表示登录后启动程序。
3. 从开始菜单或安装完成页启动程序，从托盘打开设置窗口。
4. 首次启动可能询问是否安装服务。若先测试普通桌面共享，可拒绝该提示；之后仍可在 **Other Options → Run as a service** 中开启。

默认安装目录为 `C:\Program Files\Mouse Without Borders Standalone`。请保留安装目录中的主程序、Helper、Service 及依赖文件。

## 配对两台电脑

假设两台电脑在设置界面中显示的名称分别为 `DESKTOP-A` 和 `LAPTOP-B`。这些是示例名称，请替换为各自的实际名称。

1. 在两端打开 **Machine Setup**，确认本机名称，并在 **Security Key** 中填写相同的配对密钥。可在一端使用 **New Key** 生成后填入另一端。
2. 在电脑布局中启用并填写参与共享的电脑名称，按桌面上的实际位置排列；两端使用一致的布局。
3. 在两端点击 **Apply**，等待对端状态显示 **Connected**。
4. 使用 `Ctrl+Alt+F1`、`Ctrl+Alt+F2` 切换到相应布局位置，测试键盘和鼠标。更改过快捷键时，以设置中的配置为准。
5. 在 **Other Options** 中确认 **Share Clipboard** 已启用，复制一段普通文本并在另一端粘贴，检查结果。

程序最多配置 4 台电脑，目前独立版实测覆盖两台。Easy Mouse 用于鼠标跨屏切换，实际屏幕边缘切换体验仍待验证。

## 连接失败时

先确认两端程序都在运行，版本一致，电脑名称与配对密钥填写正确。随后核对网络与防火墙规则。

| 现象 | 检查方式 |
| --- | --- |
| 对端一直无法连接 | 确认电脑间网络互通，主程序的入站 TCP 规则覆盖当前网络类型与对端地址 |
| 电脑名称无法解析 | 在 **IP Mappings** 中按界面提示配置名称到对端局域网 IP 的映射，并检查名称与布局中的名称一致 |
| IP 变化后断连 | 更新 IP 映射；若有按对端 IP 限制的防火墙规则，也需同步更新 |
| 密钥不匹配 | 重新核对两端 **Security Key**，应用设置；切换服务模式后需要重新输入配对密钥 |
| 已连接但剪贴板不共享 | 确认两端启用了 **Share Clipboard**，先用普通文本测试 |
| 找不到设置窗口 | 检查系统托盘的隐藏图标区域，从程序托盘入口打开设置 |

默认 TCP 端口为 `15100/15101`，可通过配置调整。安装器的规则按主程序路径放行 TCP，不固定端口。公共网络、域网络、跨子网与 VPN 环境可能不被默认规则覆盖，需要管理员根据实际网络配置；无需为排障关闭整个 Windows 防火墙。

## 服务模式

服务模式用于由 SYSTEM 进程在不同 Windows 桌面运行程序。当前独立版的服务安装、启用，以及锁屏、登录桌面和 UAC 安全桌面的共享行为尚未完成实测。

在 **Other Options → Run as a service** 中开启，按提示批准管理员权限并重启程序。首次启动时的服务安装提示也可用于注册和启用。取消勾选后，程序会询问是否一并卸载服务。

切换普通模式与服务模式会改变配对密钥的存储保护方式，首次切换后需在设置窗口重新输入一次配对密钥。

服务名称为 `PowerToys.MWB.Service`，与 PowerToys 相同，不能同时注册两套服务。若启动服务后 20 秒内未检测到本会话的 SYSTEM 实例，程序会提示并退回普通模式。

排障时可在管理员终端中，从安装目录执行以下维护命令：

```bash
./PowerToys.MouseWithoutBordersService.exe install
```

```bash
./PowerToys.MouseWithoutBordersService.exe uninstall
```

## 更新、登录自启与卸载

运行新版安装包可更新同一安装。更新会先停止当前安装目录中的进程；服务模式用户需重新启动主程序，程序会按现有设置运行。

若需取消登录自启，可重新运行安装包并取消相应选项，或在 Windows 的启动应用管理中禁用。当前已验证自启快捷方式可调用，注销或重启后的完整自启流程仍待验证。

从 Windows“已安装的应用”或开始菜单卸载。卸载会清理当前安装对应的服务、默认防火墙规则和快捷方式，并保留用户配置与配对数据：

```text
%LOCALAPPDATA%\Microsoft\PowerToys\MouseWithoutBorders
```

如曾手动创建防火墙规则，请自行核对和清理；安装器不会自动删除额外规则。具体更新和卸载行为见[安装包说明](../Installer/README.md)。

## 提交问题反馈

请提供 Windows 版本、程序版本、普通或服务模式、网络类型、复现步骤、预期行为与实际结果。说明问题是否双向发生、是否始终显示 Connected，以及是否修改过快捷键、IP 映射或端口。

公开日志和截图前，请移除配对密钥、私人剪贴板内容，以及不希望公开的主机名、地址和用户路径。
